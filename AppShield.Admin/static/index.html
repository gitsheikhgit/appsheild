Windows Endpoint Command Center (PowerShell / Admin)

Essential PowerShell commands to execute on the Windows PC for deployment, key retrieval, and diagnostic checks. Click any command to copy it directly to your clipboard.

1. Install Client on Windows (Run as Admin):
powershell -ExecutionPolicy Bypass -File .\Install-AppShield.ps1
2. Retrieve Pre-Shared Key (PSK) if Lost:
Get-Content "C:\ProgramData\AppShield\psk.key"
3. Verify Background Service Status:
Get-Service AppShieldService
4. Tail Live Service Diagnostic Logs:
Get-Content "C:\ProgramData\AppShield\service.log" -Tail 50 -Wait
5. Check Tailscale Mesh IP Address:
tailscale ip -4
